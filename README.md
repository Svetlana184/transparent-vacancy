## Запуск

```bash
# Установка зависимостей
npm install

# Режим API (загрузка с trudvsem.ru)
npm run api

# Проверочный режим (локальный JSON)
npm run local

# Ручной запуск с параметрами
node src/main.js run --mode local --file data/test_vacancies.json

# Запуск по расписанию
npm run schedule
```

## Обработка ошибок

- При недоступности API сервис **не перезаписывает** последний отчёт.
- В консоли появится сообщение `[FAIL-SAFE]`.
- Последний успешный отчёт всегда доступен в `data/reports/latest.json`.

## Дедупликация

Повторный запуск на тех же данных даёт **один результат на ID вакансии** — старые записи перезаписываются новыми.
